1. بنية المصادقة، تسجيل الدخول، وإدارة الهوية الأكاديمية (Authentication & Sessions)

Login.tsx • AuthContext.tsx • Register.tsx

تمت ترقية منظومة تسجيل الدخول والمصادقة بالكامل لتكون مرنة، فائقة التأمين، ومصممة لتسهيل اختبار لجان التقييم والعمل الميداني:

  • تسجيل الدخول بالبريد الجامعي والشخصي: خوارزمية تمييز آلية للنطاقات الجامعية الأكاديمية (.edu.eg)، مع تشفير كلمات المرور ومطابقة التجزئة ضد قواعد Firestore والوضع التجريبي.
  • تكامل تسجيل الدخول بـ Google OAuth مع Fallback مرن: تسجيل الدخول بضغطة واحدة عبر Google مع آلية Fallback ذكية وموثوقة لإنشاء جلسة محاكاة واقعية في حال العمل ببيئة أوفلاين أو عدم ربط النطاق في Firebase.
  • التبديل التجريبي السريع بنقرة واحدة (1-Click Preset Demo Roles): أزرار مخصصة في واجهة تسجيل الدخول تتيح للجان التقييم والمشرفين الدخول الفوري إما كـ (Super Admin) أو كـ (Student Member) دون الحاجة لكتابة بريد أو كلمة مرور.
  • نظام استعادة الحساب والـ OTP (ForgotPassword.tsx / otp.ts): رمز تحقق سري من 6 أرقام يرسل للبريد مع مهلة زمنية (Cooldown)، وعداد أقصى لمنع هجمات التخمين (Brute-Force).
  • توليد رقم العضوية الأكاديمي التلقائي: إنشاء رقم عضويّة مشفر فريد لكل طالب مسجل (DC-MEM-XXXX) لربطه بشهاداته وتذاكر حضوره.
  • إدارة الجلسات التلقائية: حفظ واسترجاع الجلسات النشطة في localStorage ومزامنتها لحظياً مع Firebase Auth لضمان عدم انقطاع الجلسة عند التحديث.

2. مصفوفة الأدوار والصلاحيات الموحدة (Strict 2-Role RBAC System)

roleDefinitions.ts • RoleGuard • AdminDashboard.tsx

تم تطهير المنصة من الرولات المتشعبة الزائدة (HR, Editor, Event Manager, Content Manager, Finance Manager) وحصر المنظومة في رولين اثنين محددين بدقة:

الرول الأكاديمي المستوى نطاق الصلاحيات وبوابات الوصول في النظام الحالة البرمجية
سوبر أدمن (super_admin) LVL 10 (Master) سلطة كاملة ومطلقة: رفع الكورسات والمناهج، إدارة الفعاليات ومسح تذاكر QR، إدارة الأعضاء وتعديل الرولات، المشاريع، المدونة، المعرض، النقاط، إعدادات الأمان وجدار الحماية، ووضع الصيانة. كامل ومفعل 100%
عضو النادي (member) LVL 1 (Student) تصفح الكورسات، دخول غرف التعلم التفاعلية، حل الاختبارات والتحديات البرمجية، التسجيل في الفعاليات، تنزيل الشهادات المعتمدة، المنافسة في لوحة المتصدرين، وتحديث الملف الشخصي. كامل ومفعل 100%

تم تأمين كافة المسارات الإدارية في AdminDashboard.tsx عبر مكوّن RoleGuard الذي يضمن وصول السوبر أدمن لكافة الشاشات دون اعتراض.

3. نظام المرشد الأكاديمي الذكي (Google Gemini AI Mentor System)

aiService.ts • AIMentorModal.tsx • @google/genai

تم تزويد المنصة بنظام مرشد افتراضي فائق الذكاء يعمل كمساعد تدريسي للطالب، مدعوم بأحدث نماذج Google Gemini الرسمية:

  • محرك الذكاء الاصطناعي الأكاديمي (aiService.ts): تكامل رسمي ومباشر عبر حزمة @google/genai لتقديم إجابات وتحليلات برمجية دقيقة وفورية للطلاب في مختلف مجالات علوم البيانات والذكاء الاصطناعي.
  • واجهة المحادثة التفاعلية (AIMentorModal.tsx): نافذة محادثة ذكية عائمة متاحة داخل غرف الكورسات وفي كافة صفحات المنصة، تدعم تنسيق Markdown، التلوين البرمجي، والتنقل السلس.
  • شرح الأكواد المعقدة (Code Explanation): تبسيط المفاهيم البرمجية والخوارزميات خطوة بخطوة للطلاب المبتدئين.
  • اكتشاف وتصحيح الأخطاء (Bug Debugging): فحص كود الطالب وتقديم تلميحات ذكية للحل دون حرق الإجابة لتعزيز التفكير النقدي.
  • التأمين والتحصين ضد الاختراق: إزالة مفاتيح الـ API الثابتة وتمريرها عبر متغيرات البيئة المشفرة، مع ضبط فلاتر سلامة صارمة لصد محاولات הـ Prompt Injection.
  • وضع الطوارئ الأوفلاين (Resilient Offline Fallback): نظام ردود ذكية محلي معد مسبقاً يعمل تلقائياً عند انقطاع الاتصال أو نفاد رصيد الـ API لضمان استمرار عمل المنصة دون أي توقف.

4. المترجم البرمجي وبيئة التشغيل المعزولة (Online Compiler Playground)

CompilerPlayground.tsx • universalRunner.ts • Web Worker Sandbox

مختبر برمجي متكامل يتيح للطلاب كتابة وتنفيذ الأكواد مباشرة داخل المتصفح دون الحاجة لتثبيت أي برامج على أجهزتهم:

  • دعم 5 لغات برمجية أساسية: تشغيل (Python, JavaScript, TypeScript, SQL, HTML/CSS) مع محرر أكواد متقدم يوفر ترقيم الأسطر والإكمال التلقائي.
  • الكونسول والطرفية الحية (Live Terminal Console): نافذة إخراج طرفية تحاكي أنظمة Linux/Bash مع دعم التلوين البرمجي، طباعة المصفوفات، وعرض سرعة التنفيذ بالأجزاء من الثانية.
  • عزل بيئة التشغيل الصارم (Web Worker Sandbox في universalRunner.ts): تنفيذ أكواد المستخدم داخل خيط معالجة منفصل تماماً (Isolated Worker)، مع حظر كامل وقاطع للوصول إلى:
    • واجهة برمجة المتصفح والـ DOM (window, document).
    • ملفات تعريف الارتباط والتخزين المحلي (localStorage, cookies, sessionStorage).
    • طلبات الشبكة الخارجية (fetch, XMLHttpRequest, WebSocket) لمنع تسريب البيانات.
  • حماية ضد التجميد (Execution Timeout): مؤقت أمني يقطع تنفيذ الكود قسرياً بعد 5 ثوانٍ لحماية جهاز المستخدم من الحلقات اللانهائية (Infinite Loops) واستنزاف الذاكرة.

5. منظومة إدارة ورفع الكورسات وغرف التعلم (Course LMS & Management)

CourseManagement.tsx • courseService.ts • CourseLearning.tsx
  • رفع صور الأغلفة من الجهاز مباشرة: دمج أداة ImagePicker لدعم رفع الصور مباشرة من ملفات الكمبيوتر أو الهاتف، أو التقاط صورة حية، أو وضع رابط ويب خارجي، مع المعاينة الفورية قبل الحفظ.
  • واجهة ثنائية اللغة بالكامل (Arabic / English): تعريب شامل للجدول، العناوين، حقول الإدخال، والأزرار وفق لغة الواجهة.
  • بيانات أكاديمية تفصيلية شاملة: حقول (العنوان، Slug مخصص أو مولد تلقائياً، التصنيف الأكاديمي، المستوى، نقاط الـ XP، المدة بالساعات، إجمالي الدروس، اسم المحاضر، النبذة السريعة، والمنهج التفصيلي الكامل).
  • حالة النشر الأكاديمي: خيار حفظ الدورة كـ (منشور للطلاب Published) أو (مسودة خاصة Draft).
  • التوليد التلقائي للوحدات والدروس (courseService.ts): ربط تلقائي فوري لأي كورس جديد بوحدات ودروس تفاعلية تمنع ظهور أي شاشات فارغة، وتسمح للطلاب ببدء التعلم فوراً دون أخطاء.
  • غرفة التعلم التفاعلية المتزامنة (CourseLearning.tsx): مشغل فيديو مدمج، دروس نصية، اختبارات تقييمية (Quizzes) بنسبة اجتياز 70%، وحساب ديناميكي لنسبة إنجاز الطالب.
  • أزرار إجراءات الجدول السريعة: زر معاينة الكتالوج (/courses/:slug)، زر دخول غرفة التعلم (/courses/:slug/learn)، وزر التعديل والحذف مع تأكيد الحذف الفوري.

6. محرك وتصميم الشهادات الأكاديمية والطباعة (Academic Certificate Engine)

CertificateView.tsx • Certificates.tsx • jsPDF
  • دقة سينمائية فائقة (2400 × 1700 Ultra-HD Canvas): تصميم هندسي فاخر يجمع بين اللون الكحلي الفلكي وخطوط النيون الذهبية والسيان، مع إطار ثلاثي الطبقات متدرج ونقوش زوايا ملكية.
  • هوية أكاديمية رسمية: شعار نادي DataCamp المعتمد، ختم ذهبي تفاعلي (Holographic Gold Seal)، توقيعات العميد والمرشد، ورقم توثيق تشفيري فريد.
  • معالجة الخطوط وحجم الاسم: تكبير وتنسيق اسم الطالب ليكون بارزاً وفخماً ومقروءاً بوضوح بخط عربي وإنجليزي احترافي منسق.
  • أزرار تنزيل مباشر بنقرة واحدة دون تهنيج:
    • تنزيل كصورة (PNG): تنزل مباشرة إلى مجلد التنزيلات بالجهاز دون طلب صلاحيات إضافية أو كتابة مباشرة على القرص.
    • تنزيل كـ PDF عالي الجودة: توليد ملف PDF متجهي عبر jsPDF جاهز للطباعة الورقية فوراً بأبعاد A4 قياسية.
  • باركود QR للتحقق السحابي المستقل: مسح الباركود يوجه مباشرة إلى صفحة التحقق الرقمية العامة (/verify-certificate/:code) للتأكد من أصالة وصحة بيانات الشهادة.
